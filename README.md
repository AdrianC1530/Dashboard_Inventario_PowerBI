# Dashboard de inventario de repuestos (Power BI)

Página web que presenta un **dashboard de inventario de repuestos** construido en **Power BI**,
con capturas de sus principales vistas.

## Cómo verlo

Abrir `index.html` en el navegador.

## Tecnologías

Power BI, HTML, CSS.

## Archivos de Power BI

- `powerbi/clase2904.pbix`: práctica de clase de Power BI.
- `powerbi/Taller0605.pbix`: taller del dashboard de inventario.

Se abren con Power BI Desktop.
